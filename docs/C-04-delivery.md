## 一、交付格式（新制）

### 1.1 每檔交付

**標題格式**：

> ## 交付路徑：
> 📁 檔案路徑
> （檔名）
> 完整相對路徑
>
> ## 交付內容：
> 📄 檔案內容(類別)
> 編寫者：A20261013-001#005
> （| Unix_epoch | YYYY-MM-DD HH:mm）

**欄位**：

| 欄位 | 值 |
|---|---|
| 檔名 | 純檔名 |
| 完整路徑 | 相對根目錄 |
| 類別 | 新增 / 修改 |
| 編寫者 | A{YYMMDD}-{序號}#{回覆序號} |
| Unix_epoch | 10 位數字 |
| 時間 | 人類可讀（輔助） |

### 1.2 批次交付開頭

**格式**：

> 📦 B{n}：第 {N}/{M} 批（{X} 檔）
>
> 交付時間：YYYY-MM-DD HH:mm
> Unix epoch：{10 位}
> 編寫者：A{YYMMDD}-{序號}#{回覆序號}

---

## 二、END OF FILE 格式

**格式**（四行結構）：

> /\* ═══ EOF ═══
> F: 完整路徑
> V: Unix epoch
> B: 批次號
> W: 編寫者#序號
> ═══ \*/

| 縮寫 | 全稱 |
|---|---|
| F | File |
| V | Version |
| B | Batch |
| W | Writer |

**註解符號**：

| 檔案 | 符號 |
|---|---|
| .js / .css | 斜線星號（成對） |
| .md | 斜線星號 或 HTML 註解 |
| .html | HTML 註解 |
| .json | 不支援 |

## 六、backtick 嵌套規則

| 內層最多 | 外層 |
|---|---|
| 3 個 | 4 個 |
| N 個 | N + 1 個 |

**md 檔案內**：遵守 §六點五（零三反引號）。

**真代碼檔案（.js / .html / .css）**：若需展示範例含三反引號，外層 = 內層 + 1。

---

## 六點五、md 檔案寫作規則（強制）

**核心**：md 檔案內**零三反引號**。

| 情境 | 寫法 |
|---|---|
| 多行展示 / 範例 | `>` 引用塊 |
| 單行關鍵字 | 行內單反引號 |
| 結構化內容 | markdown 表格 |
| 真代碼 | 另存獨立檔案 |

**判準**：
- 「要複製去執行的」→ 獨立檔案
- 「只是展示樣子的」→ 引用塊

**理由**：md 檔案內的三反引號，會被渲染成灰框 + 複製/下載按鈕，干擾閱讀。

**唯一例外**：無。

## 七、檔案大小與命名

| 類型 | 若超標 | 處理 |
|---|---|---|
| Page Schema | > 300 | 抽 customMount 邏輯至 lib |
| Block | > 300 | 抽共用邏輯至 lib |
| Lib | > 250 | 拆為多個 lib |
| Engine | > 500 | 拆引擎 |
| Functions API | > 800 | 拆 handler |

**命名慣例**：

| 類型 | 慣例 |
|---|---|
| 檔案 | kebab-case |
| 類別 | PascalCase |
| 公開函式 | camelCase |
| 常數 | UPPER_SNAKE_CASE |
| 私有 | 底線開頭 |

## 八、常見錯誤修正

| # | 錯誤 | 正確 |
|---|---|---|
| 1 | 只給 diff | 完整檔案 |
| 2 | 用「...」「同上」 | 完整列出 |
| 3 | 多檔合併 | 每檔獨立 |
| 4 | 內層三反引號 | 外層 = 內層 + 1 |
| 5 | 忘 EOF | 必加 |
| 6 | 檔案 > 500 行 | 拆檔 |
| 7 | 忘 Token 狀態 | 見 C-02 §零點五 |
| 8 | 未標交付類型 | 必標 |
| 9 | 未附追蹤表 | 必附 |
| 10 | 未附單行索引 | 必附 |
| 11 | Version 用舊制 | 用 Unix epoch |
| 12 | 未標編寫者 | 必標 |
| 13 | **md 內用三反引號** | **改引用塊** |

## 十二、交付前自我檢查

### 檔案層

| 檢查項 |
|---|
| 路徑清晰 |
| 內容完整 |
| 含 EOF（F/V/B/W） |
| **md 內無三反引號** |
| backtick 嵌套正確（真代碼檔） |
| 交付類型已標示 |
| 編寫者已標 |

### 方案層

| 檢查項 |
|---|
| 已跑 5 問自檢 |
| 已掃描實際檔數 |
| 交付摘要含最小改動對比 |
| 能解釋「為何不是 N-1」 |

### 追蹤層

| 檢查項 |
|---|
| 單行索引已附 |
| 本對話追蹤表已附 |
| Token 狀態已顯示 |
