## 一、交付格式（兩層規則）

### 1.1 每檔交付

**標題格式**（純文字）：

> ## 交付路徑：
> 📁 檔案路徑
> （檔名）
> 完整相對路徑
>
> ## 交付內容：
> 📄 檔案內容(類別)
> 編寫者：A20261013-001#014
> （| Unix_epoch | YYYY-MM-DD HH:mm）

**檔案內容**：**必須用三反引號包裹**（附語言標示）

| 檔案 | 語言標示 |
|---|---|
| .js | js |
| .md | md |
| .json | json |
| .css | css |
| .html | html |
| .txt | text |

### 1.2 批次交付開頭

**格式**（純文字）：

> 📦 B{n}：第 {N}/{M} 批（{X} 檔）
>
> 交付時間：YYYY-MM-DD HH:mm
> Unix epoch：{10 位}
> 編寫者：A{YYMMDD}-{序號}#{回覆序號}

## 二、兩層三反引號規則（強制）

**核心**：分「外層」與「內層」。

### 2.1 外層（AI 交付時）

| 情境 | 寫法 |
|---|---|
| AI 交付任何檔案內容 | **必須用三反引號包裹** |
| 目的 | 提供「一鍵複製」按鈕 |

**禁止**：直接寫（不包裹）→ 使用者無法一鍵複製。

### 2.2 內層（md 檔案內部）

| 情境 | 寫法 |
|---|---|
| md 內展示格式 / 範例 | 引用塊（`>`） |
| md 內單行關鍵字 | 行內單反引號 |
| md 內結構化內容 | markdown 表格 |
| md 內真代碼 | 另存獨立檔案 |

**禁止**：md 內用三反引號。

**理由**：md 內的 ``` 會被 GitHub / DeepSeek 渲染成灰框，干擾閱讀。

### 2.3 內層（真代碼檔案）

| 情境 | 寫法 |
|---|---|
| .js / .html / .css 內含 ``` | 正常（因為是代碼） |
| .js 內若需展示含 ``` 的範例 | 外層 = 內層最多 + 1 |

---

## 三、END OF FILE 格式

**格式**（真代碼，用三反引號包裹）：

> /\* ═══ EOF ═══
> F: 完整路徑
> V: Unix epoch
> B: 批次號
> W: 編寫者#序號
> ═══ \*/

| 縮寫 | 全稱 |
|---|---|
| F | File |
| V | Version |
| B | Batch |
| W | Writer |

**註解符號**：

| 檔案 | 符號 |
|---|---|
| .js / .css | 斜線星號（成對） |
| .md | 斜線星號 或 HTML 註解 |
| .html | HTML 註解 |
| .json | 不支援 |

## 四、單行索引

**每批交付開頭附**：

> 📦 B32-2 [1791886800]
>
> docs/C-02-rules.md      V:1791886800 W:A20261013-001#014
> docs/C-04-delivery.md   V:1791886800 W:A20261013-001#014

**格式**：路徑 V:epoch W:writer（每檔一行）

## 六、交付類型標示

| 標示 | 含義 |
|---|---|
| （新增） | 全新檔案 |
| （修改） | 完整替換舊檔 |
| （片段 - 違反規則） | 只給片段（例外） |

---

## 七、backtick 嵌套規則

| 內層最多 | 外層 |
|---|---|
| 3 個 | 4 個 |
| N 個 | N + 1 個 |

**若無法判斷** → 用引用塊或表格說明。

**md 檔案內**：遵守 §二（零三反引號）。

---

## 八、常見錯誤修正

| # | 錯誤 | 正確 |
|---|---|---|
| 1 | 只給 diff | 完整檔案 |
| 2 | 用「...」「同上」 | 完整列出 |
| 3 | 多檔合併 | 每檔獨立 |
| 4 | 內層三反引號 | 外層 = 內層 + 1 |
| 5 | 忘 EOF | 必加 |
| 6 | 檔案 > 500 行 | 拆檔 |
| 7 | 忘 Token 狀態 | 見 C-02 §零點五 |
| 8 | 未標交付類型 | 必標 |
| 9 | 未附追蹤表 | 必附 |
| 10 | 未附單行索引 | 必附 |
| 11 | Version 用舊制 | 用 Unix epoch |
| 12 | 未標編寫者 | 必標 |
| 13 | md 內用三反引號 | 改引用塊 |
| 14 | **交付時未用 ``` 包裹** | **必須包裹** |

## 九、多批交付

| 檔案行數 | 每批檔數 |
|---|---|
| < 200 行 | 3~4 檔 |
| 200~400 行 | 2 檔 |
| > 400 行 | 1 檔 |

## 十二、交付前自我檢查

### 檔案層

| 檢查項 |
|---|
| 路徑清晰 |
| 內容完整 |
| **內容用 ``` 包裹（外層）** |
| 含 EOF（F/V/B/W） |
| **md 內零三反引號（內層）** |
| 交付類型已標示 |
| 編寫者已標 |

### 方案層

| 檢查項 |
|---|
| 已跑 5 問自檢 |
| 已掃描實際檔數 |
| 交付摘要含最小改動對比 |
| 能解釋「為何不是 N-1」 |

### 追蹤層

| 檢查項 |
|---|
| 單行索引已附 |
| 本對話追蹤表已附 |
| Token 狀態已顯示 |
