# C-02 通用規則（跨專案）

最後更新：B30-6

## 零、Token 不足處理（最高優先）

**原則**：交付前若預估 token 不足，**不得自主交付刪減版**。

| 情境 | 判斷 | AI 動作 |
|---|---|---|
| Token 足夠 | 本次可完整交付 | 交付完 → 問「是否繼續交付第 N 批？」 |
| Token 不足 | 本次無法完整交付 | 提示 + 提供新對話開場白 |

**禁止**：

| 禁止 | 說明 |
|---|---|
| 自主刪減檔案內容 | 不得省略、不得用「...」「同上」 |
| 自主分批但未說明 | 必須明確告知 |
| 交付未完整檔案 | 每批必須完整 |
| 用「token 不夠」為由降低品質 | 應分批，不應降質 |

## 零點五、Token 視覺化（每個回覆結尾）

**原則**：每次回覆交付完成後，**必須在回覆結尾顯示 Token 狀態**。

| Emoji | 剩餘 | 行為 |
|---|---|---|
| 🟢 | ≥ 50% | 正常交付，問「是否繼續下一批？」 |
| 🟡 | 20~49% | 提示「Token 偏低」，問「是否繼續？」 |
| 🔴 | < 20% | 提示「Token 不足」，提供新對話開場白 |

**格式**：分隔線 + `Token: {emoji} [{bar}] {pct}% 剩餘`

## 一、核心原則（最高優先）

| # | 原則 | 說明 |
|---|---|---|
| 1 | 先方案後交付 | 未確認不交付 |
| 2 | 最小改動優先 | 5 問自檢 |
| 3 | 極簡優先 | 能 1 檔不改 2 檔 |
| 4 | SSOT 極大化 | 邏輯集中 1 處 |
| 5 | AI 優先 | 為 AI 可讀性優化 |

---

## 二、問題處理流程

| 步驟 | 動作 |
|---|---|
| 1 | 診斷（根本原因） |
| 2 | 建立對照組（見 C-07 §二） |
| 3 | 跑 5 問自檢 |
| 4 | 提供「方案 + 對比表」 |
| 5 | 待使用者確認 |
| 6 | 確認後才交付 |

---

## 三、主動提案義務

| 情境 | AI 應做 |
|---|---|
| 看到更好方案 | 主動提出 |
| 決策不合理 | 明確反對並說明 |
| 使用者方案不理想 | 誠實告知「理想化」 |
| 發現漏洞 | 主動指出 |

**禁止**：因「使用者已決定」而放棄建議；明知有問題仍照做。

---

## 四、5 問自檢（提方案前必做）

| # | 問題 | 若答「是」 |
|---|---|---|
| 1 | 能不能只改 1 檔？ | 到此為止 |
| 2 | 能否改集中層？ | 改集中層 |
| 3 | 各檔改動可否用「預設值」吸收？ | 呼叫端不動 |
| 4 | 可否加參數（向後相容）解決？ | 舊呼叫不動 |
| 5 | 現有架構是否已提供切入點？ | 用現有 |

**交付摘要必附 3 欄位**：

| 欄位 | 內容 |
|---|---|
| 改動檔案數 | N |
| 最小改動路徑 | 如何得出 N |
| 為何不是 N-1 | 為何不能再少 |

---

## 五、禁止事項

| 禁止 | 說明 |
|---|---|
| 猴子補丁 | 改引擎不改呼叫端 |
| 加快取變數判斷資料 | 用 onDataChange |
| 從現況推論範圍 | 從理想設計推論 |
| 把「統一」誤解為「各頁都改」 | 統一 = 邏輯集中 |
| 未掃描就估檔數 | 先掃描 |
| 為避免新增檔案而妥協 | 該新增就新增 |
| 為人類可讀性犧牲簡潔 | AI 優先 |
| 交付含嵌套未用外層 +1 | 見第六節 |
| 未顯示 Token 狀態 | 見零點五節 |

---

## 六、檔案規則

| 規則 | 說明 |
|---|---|
| 檔案 ≤ 500 行 | 超過拆檔 |
| 檔案結束標記 | END OF FILE（必加） |
| 交付完整 | 不用 diff / 「...」 |
| 每檔獨立 | 不合併 code block |
| backtick 嵌套 | 外層 = 內層 + 1 |

**backtick 嵌套強制檢查**：

| 步驟 | 動作 |
|---|---|
| 1 | 掃描內層 backtick 數 |
| 2 | 外層 = 內層最多 + 1 |
| 3 | 交付摘要標示「嵌套檢查 ✅」 |

## 七、自我完善機制

| 情境 | AI 動作 |
|---|---|
| 對話結束 | 檢查是否有新經驗 |
| 使用者糾正 | 立即建議記錄 |
| 發現新反例 | 建議記錄到 learning |
| 使用者表達偏好 | 建議記錄到 profile |

**Reflexion 格式**：場景 / 錯誤 / 正確做法 / 適用規則。

**記憶提升**：

| 層級 | 檔案 | 上限 |
|---|---|---|
| L1 工作記憶 | 當前對話 | — |
| L2 短期 | C-05-learning.md | 100 行 |
| L3 長期 | C-01 / C-02 | 150 / 200 行 |

## 十一、CF Pages Functions 環境變數

| 項目 | 說明 |
|---|---|
| ❌ 錯誤 | `process.env.DB_TARGET` |
| ✅ 正確 | handler 參數 `{ env }` → `env.DB_TARGET` |
| 傳遞 | 每個 `onRequest*` 開頭呼叫 `initConfig(env)` |
