## 十三、貼 URL 啟動（D-136）

### 13.1 使用者貼 2 條 STARTUP URL

| 步驟 | AI 動作 |
|---|---|
| 1 | 讀取 URL 內容 |
| 2 | 生成對話編號 |
| 3 | 提示下一議題 + 列 4 選項 |
| 4 | 依情境處理 |

### 13.2 使用者貼 INDEX.md URL

| 步驟 | AI 動作 |
|---|---|
| 1 | 讀取 INDEX.md |
| 2 | 列出所有專案 + 領域 |
| 3 | 問「要哪個專案」 |
| 4 | 給 2 條 STARTUP URL |
| 5 | 使用者貼 2 條 URL |
| 6 | 後續同 13.1 |

### 13.3 使用者選「新專案」

| 步驟 | AI 動作 |
|---|---|
| 1 | **問「這個專案屬於哪個領域？」** |
| 2 | 使用者回答（Web App / VBA / …） |
| 3a | 已有領域 → 直接開新專案 |
| 3b | 新領域 → 主動建議建 6 檔 |
