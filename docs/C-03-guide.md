# C-03 流程指南

最後更新：B29-7
版本：v1.0
用途：AI 執行流程 + 決策樹

---

## 一、開場 SOP

**AI 讀 C-00-startup 後**：

| 步驟 | 動作 |
|---|---|
| 1 | 回報「已讀取 startup」 |
| 2 | 列 4 選項 |
| 3 | 待使用者選擇 |

**使用者選後**：

| 情境 | AI 動作 |
|---|---|
| 新專案 | 請求 C-01~C-05 |
| 舊專案 | 請求 C-01~C-05 + P-* 全部 |
| 純討論 | 直接討論 |
| 其他 | 依說明 |

## 二、讀取決策樹

| 4 | 跑 5 問自檢 |
| 5 | 列變更對照 |
| 6 | 待確認 |

## 三、上下文路由（AI 自動判斷）

| 使用者在做 | AI 自動讀 |
|---|---|
| 準備交付 | P-99-errors-map |
| 討論架構 | P-02-anchor |
| 修 Bug | P-incident + P-99-errors-map |
| 改 UI | P-uispec |
| 改 API | P-api |
| 改資料 | P-data + P-compat |

→ **使用者不需說讀哪檔**。

## 四、三層讀取策略

| 層級 | 檔案 | 讀取時機 |
|---|---|---|
| L1 必讀 | C-00 ~ C-05 | 每次對話 |
| L2 概覽 | P-01 ~ P-04 | 舊專案啟動時 |
| L3 細節 | P-05 ~ P-98 | 按需（AI 判斷） |
| 特殊 | P-99-errors-map | 交付前必讀 |

---

## 五、對話流程（典型）

| 步驟 | 誰 | 動作 |
|---|---|---|
| 1 | 你 | 上傳 C-00-startup |
| 2 | 你 | 貼「請讀取 docs/」 |
| 3 | AI | 讀 + 列 4 選項 |
| 4 | 你 | 選情境 |
| 5 | AI | 請求對應檔案 |
| 6 | 你 | 上傳 |
| 7 | AI | 讀 + 回報狀態 |
| 8 | 你 | 說明需求 |
| 9 | AI | 跑 5 問 → 提供方案 |
| 10 | 你 | 確認 |
| 11 | AI | 交付 |
| 12 | 你 | 測試回報 |
| 13 | AI | 修正或完成 |
| 14 | AI | 對話結束前綜合記憶 |

---

## 六、中途切換情境

**使用者說「切換情境」**：

| 步驟 | AI 動作 |
|---|---|
| 1 | 確認「放棄當前情境？」 |
| 2 | 重列 4 選項 |
| 3 | 依新情境走 |

---

## 七、對話結束記憶綜合

**觸發時機**：

| 觸發 | 動作 |
|---|---|
| 使用者說「結束對話」 | 執行綜合 |
| 使用者說「再見 / 之後再說」 | 執行綜合 |
| AI 感知對話自然結束 | 主動建議 |

**執行步驟**：

| 步驟 | 動作 |
|---|---|
| 1 | 回顧本次對話 |
| 2 | 提取新經驗（Reflexion 格式） |
| 3 | 寫入 C-05-learning |
| 4 | 若達閾值 → 建議提升 |
| 5 | 生成「進化報告」 |
| 6 | 待確認後更新 |

---

## 八、新專案骨架判斷

**AI 依描述判斷**：

| 專案特徵 | 建議檔數 |
|---|---|
| 純靜態 / 單頁 | 2 檔 |
| 有狀態 / 多頁 | 4 檔 |
| 有架構 / 多模組 | 6 檔 |
| 複雜 / 多人協作 | 全部 |

**AI 主動說明 → 使用者確認 → 才建檔**。

## 九、常見錯誤（禁止）

| 錯誤 | 正確 |
|---|---|
| 未經確認直接改檔 | 先方案 |
| 直接估算 N 檔 | 先掃描 |
| 從現況推論範圍 | 從理想推論 |
| 忽略使用者偏好 | 讀 C-01 |
| 忘記記錄教訓 | 對話結束綜合 |
