### P21 hideCompleted 誤過濾

| 項目 | 內容 |
|---|---|
| 症狀 | 部署 B25-3c 後，結算清單完全沒資料 |
| 原因 | 把 `hideCompleted` 放進 `filters`，被 `applyFilters` 誤當作 row 過濾條件（`row.hideCompleted !== true` → 全數排除） |
| 解決 | `hideCompleted` 移出 `filters`，改放獨立 `state.hideCompleted` |
| 引入批次 | B25-3c（我引入） |
| 修復批次 | B25-3d |
| 教訓 | `filters` 只放「會過濾 row 的欄位」；UI 控制變數獨立放 state |

## 核心教訓總結

### CF Pages

| 教訓 | 說明 |
|---|---|
| Functions 路由 | 每個 URL 對應獨立實體檔 |
| 不支援 shim | 用底線前綴 + Catch-all |
| 靜態檔案 | 所有連結帶 .html |
| _redirects | 不要對 / 加規則 |

### Page Engine

| 教訓 | 說明 |
|---|---|
| customMount | 必須支援 |
| onDataChange | 必須支援 |
| 依賴圖 | key 與事件觸發一致 |
| undefined | derived 需容忍 |
| 動態 import 慎用 | 需有錯誤處理 |

### 程式碼

| 教訓 | 說明 |
|---|---|
| esc 路徑 | 從 lib/dom.js |
| format* 路徑 | 從 lib/format.js |
| 檔案搬移 | 全域搜尋舊路徑 |
| 無補丁 | 寧願重寫 |
| **狀態字串** | 一律走 status-registry |
| **filters** | 只放 row 過濾欄位 |
